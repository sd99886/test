# 退货原因分析

## 使用流程

### Step 1：确认数据来源

向用户确认两种输入方式之一：

| 方式 | 说明 |
|------|------|
| **A. 自动取数** | 调用 `odps-query` skill 执行 `sql/return_reason_query.sql`，需先确认筛选条件 |
| **B. 上传文件** | 用户直接提供 Excel/CSV，跳过取数直接进入分析 |

### Step 2：确认筛选条件（仅自动取数时需要）

**必须**向用户逐项确认以下条件：

> ⚠️ **数据范围说明**：本技能仅获取 `channel = '独立站'` 的数据，不含 Amazon / Zalando 等渠道。

| # | 确认项 | 对应字段 | 示例 | 默认值 |
|---|--------|---------|------|--------|
| 1 | 销售时间范围 | `date_str` | `>= '2026-08-01' AND <= '2026-10-31'` | 全量（不限） |
| 2 | 上新时间范围 | `首次上架时间` | `>= '2026-01'` | 全量（不限） |
| 3 | SKC | `rid.skc` | `'CAB03C6H001JK'` 或 `IN (...)` | 全量（不限） |
| 4 | 业务部门 | `cud.业务部门` | `'ACC'` | 全量（不限） |
| 5 | 大类别 | `cud.大类别` | `'鞋品'` | 全量（不限） |

**如无明确指出，则默认全量（不加该条件）。**

确认示例对话：
```
请确认以下筛选条件（不填则默认全量）：
1. 销售时间范围？（如 2026-08 ~ 2026-10）
2. 上新时间范围？（如 >= 2026-01）
3. 指定 SKC？（如 CAB03C6H001JK，多个用逗号分隔）
4. 业务部门？（如 ACC）
5. 大类别？（如 鞋品）

注意：数据仅包含 channel='独立站' 的数据。
```

### Step 3：取数 → 分析

1. 将确认的条件填入 `sql/return_reason_query.sql` 模板（替换占位符）
2. 调用 `odps-query` 执行查询，导出为 Excel
3. 按下方 7 大板块执行分析

### Step 4：确认交付方式

分析完成后，**必须**询问用户：

```
分析已完成，请选择交付方式：
A. Excel 文件（.xlsx）
B. 飞书电子表格
```

| 选项 | 执行动作 |
|------|----------|
| **A. Excel 文件** | 调用 `scripts/write_excel.py` 将结论写入新 Sheet，输出 `原文件名_含分析结论.xlsx` |
| **B. 飞书电子表格** | 调用飞书 API 创建电子表格，写入数据明细 + 分析结论各板块，将链接返回给用户 |

**飞书电子表格交付流程**：
1. 使用飞书应用身份创建电子表格（`POST /sheets/v3/spreadsheets`）
2. 将原始数据写入「数据明细」Sheet
3. 将 7 大板块分析结论依次写入「分析结论」Sheet
4. 应用颜色高亮（红/黄/绿）
5. 将电子表格链接返回给用户

## SQL 取数模板

查询模板位于 `sql/return_reason_query.sql`，核心结构：

- **主表**：`cupshe_bigdata_ads.ads_scm_cp_refund_info_df`（退货明细）
- **维表**：`cupshe_bigdata_cdm.dws_prod_skc_label_di` + `dws_prod_skc_with_combination_label_di`（SKC 维度）
- **固定条件**：`rid.channel = '独立站'`
- **聚合粒度**：销售月 × cp × skc × 首次上架时间 × 一/二/三级退货原因 × 品类

输出字段：销售月、cp、skc、品类（一/二/三级）、图片链接、首次上架时间、sku级别一/二/三级原因、销量、GMV、退款数量、退款金额、退券金额、退款总额、退件率、退款率、退券率、退货率

## 分析框架（7 个板块）

### 一、整体退货概况

| 指标 | 计算方式 |
|------|---------|
| 总销量 | SUM(销量) |
| 总退款数量 | SUM(退款数量) |
| 总 GMV | SUM(GMV) |
| 总退款金额 | SUM(退款金额) |
| 退件率 | 总退款数量 / 总销量 |
| 退货率 | 总退款金额 / 总 GMV |

### 二、退货原因分布

按一级原因聚合，退款数量降序。核心原因（占比 > 20%）下钻二级原因 TOP 3。

### 三、分月退货趋势

按月份聚合，自动标注：
- 退件率最高月 → 🔴 峰值
- 环比下降的最低月 → 🟢 改善
- 环比上升月 → 🟡 恶化

### 四、分月退货原因明细

每月 × 每原因。退件率 > 50% 标红；首次出现标注"新问题"。

### 五、深层问题诊断

对占比 TOP 2 原因做深层诊断（数据支撑 + 趋势 + 严重度 + 结论）。

严重度：占比 > 30% 或退件率 > 50% → 🔴 高；15-30% → 🟡 中；< 15% → 🟢 低

### 六、改善建议

| 优先级 | 含义 |
|--------|------|
| P0 | 立即行动（影响大 + 可快速落地） |
| P1 | 短期跟进（需一定周期） |

自动匹配建议类型：
- 尺码类 → 调整鞋楦 / 更新尺码表
- 面料类 → 面料升级 / 加衬里
- 描述类 → 更新产品图 / 增加说明

### 七、改善目标

现状 vs 目标对比 + TOP 3 行动项。

## 输出规范

### 方式 A：Excel 文件

使用 `scripts/write_excel.py`，复制原文件为 `原文件名_含分析结论.xlsx`，新增「分析结论」Sheet。

### 方式 B：飞书电子表格

调用飞书 API 创建电子表格，包含：
- Sheet 1「数据明细」：原始查询结果
- Sheet 2「分析结论」：7 大板块分析结论（扁平化为表格行）

创建后返回飞书电子表格链接。

### 颜色规范

| 颜色 | 含义 | 场景 |
|------|------|------|
| 🔴 红 (FFC7CE) | 高风险 | 占比 > 30% / 退件率 > 50% / 峰值月 |
| 🟡 黄 (FFEB9C) | 需关注 | 占比 15-30% / 退件率 25-50% / 恶化月 |
| 🟢 绿 (C6EFCE) | 已改善 | 环比下降 / 低风险 |

### 样式

标题深蓝底白字、板块浅蓝底、表头蓝底白字、数据行白底、冻结首行。
