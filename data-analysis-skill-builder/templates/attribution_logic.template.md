## L2 原子方法（可复用的分析模式）

### MTD-01 整体概览

- **触发：** "整体""分布""概览""全景"
- **适用表：** 所有表
- **参数：** 时间窗口（${start}, ${end}）、分组维度、度量字段
- **步骤：**
  1. 按维度分组聚合度量和实体数
  2. 用窗口函数计算占比
- **伪 SQL：**

```sql
SELECT  {{DIM}}, SUM({{MEASURE}}) AS qty,
        COUNT(DISTINCT {{ENTITY_ID}}) AS orders,
        ROUND(SUM({{MEASURE}}) * 100.0 / SUM(SUM({{MEASURE}})) OVER (), 2) AS pct
FROM    {{T_ID}}
WHERE   {{TIME_FILTER}} BETWEEN '${start}' AND '${end}'
GROUP BY {{DIM}}
ORDER BY qty DESC;
```

- **输出：** 维度 × 度量 × 占比分布表
- **陷阱：** 无——这是所有分析的起点
- **特别提示：** 任何归因分析都先跑此方法取整体基线，再按方法链下钻

### MTD-02 排行下钻

- **触发：** "排行""Top/Bottom""最好/最差""哪些最多"
- **适用表：** 所有表
- **参数：** 排序指标、维度、Top N、体量门槛
- **步骤：**
  1. 按维度聚合排序指标
  2. 应用体量过滤（如剔除 GMV 占比 < 2%）
  3. 排序取 Top/Bottom N
- **伪 SQL：**

```sql
SELECT  {{DIM}}, SUM({{MEASURE}}) AS qty, COUNT(DISTINCT {{ENTITY_ID}}) AS orders
FROM    {{T_ID}}
WHERE   {{TIME_FILTER}} BETWEEN '${start}' AND '${end}'
GROUP BY {{DIM}}
HAVING  {{VOLUME_FILTER}}
ORDER BY qty DESC
LIMIT   ${N};
```

- **输出：** 排序清单表
- **陷阱：** 小体量噪声——必须先过体量门槛再排行
- **特别提示：** —

### MTD-03 时间趋势

- **触发：** "趋势""走势""变化""拐点""近N天/月"
- **适用表：** 所有表
- **参数：** 时间粒度（日/周/月）、维度、指标
- **步骤：**
  1. 按时间粒度聚合
  2. 画趋势线 / 算滑动均值
  3. 识别拐点或连续下滑
- **伪 SQL：**

```sql
SELECT  SUBSTR({{TIME_FIELD}}, 1, 7) AS month,
        SUM({{MEASURE}}) AS total_qty
FROM    {{T_ID}}
WHERE   {{TIME_FILTER}} BETWEEN '${start}' AND '${end}'
GROUP BY SUBSTR({{TIME_FIELD}}, 1, 7)
ORDER BY month;
```

- **输出：** 趋势折线图 + 数据表
- **陷阱：** 日粒度噪声大，建议周粒度；单维度日量小时提示波动大、不宜过度解读
- **特别提示：** —

### MTD-04 前后对比

- **触发：** "前后""对比""效果""切换/上线后"
- **适用表：** 所有表
- **参数：** 事件日期（${event_date}）、前窗口、后窗口（等长）、分组维度
- **步骤：**
  1. 校验前后窗口等长，剔除大促/异常日
  2. 按维度分组算两窗口指标
  3. 算变化量与变化率
- **伪 SQL：**

```sql
SELECT  CASE WHEN {{TIME_FILTER}} < '${event_date}' THEN '前' ELSE '后' END AS period,
        SUM({{MEASURE}}) AS qty
FROM    {{T_ID}}
WHERE   {{TIME_FILTER}} BETWEEN '${start}' AND '${end}'
GROUP BY CASE WHEN {{TIME_FILTER}} < '${event_date}' THEN '前' ELSE '后' END;
```

- **输出：** 维度 × 前后对比表 + 变化率
- **陷阱：** 窗口不等长、跨大促异常日、比率指标直接对率值求平均（应分子分母分别聚合后再除）
- **特别提示：** 若发现几乎所有维度值同向变化（如全渠道齐跌），多半是季节性/大促等共同因素，**不要直接归因于策略变更**，应补充业务特有的 DID（同比差分）方法剥离季节性后再判断

### MTD-05 环比/同比

- **触发：** "环比""同比""短期波动""年度趋势"
- **适用表：** 所有表
- **参数：** 对比方式（环比/同比）、指标
- **步骤：**
  1. 环比 = (本周期 − 上一周期) / 上一周期
  2. 同比基准取 T − 364 天（52 整周对齐星期，**非去年同日历日**）
- **伪 SQL：**

```sql
-- 环比：本期 vs 上期（等长窗口）
-- 同比：基准取 T − 364 天（52 整周对齐星期），禁用去年同日历日
```

- **输出：** 环比% / 同比% 变化表
- **陷阱：** 同比基准必须用 T−364（对齐星期），禁止用去年同日历日
- **特别提示：** —

### MTD-06 交叉分析

- **触发：** "交叉""XX 和 YY 的关系""不同 XX 下 YY 差异"
- **适用表：** 所有表
- **参数：** 维度 A、维度 B、度量
- **步骤：**
  1. 按两维度分组聚合
  2. 发现结构性差异（如某站点某指标异常高）
- **伪 SQL：**

```sql
SELECT  {{DIM_A}}, {{DIM_B}}, SUM({{MEASURE}}) AS qty
FROM    {{T_ID}}
WHERE   {{TIME_FILTER}} BETWEEN '${start}' AND '${end}'
GROUP BY {{DIM_A}}, {{DIM_B}}
ORDER BY qty DESC;
```

- **输出：** 两维度交叉表
- **陷阱：** 交叉维度过多时结果行数爆炸，需加 HAVING 或 LIMIT
- **特别提示：** —

### MTD-07 探查枚举

- **触发：** 字段取值未知、枚举值不确定、映射关系不明
- **适用表：** 所有表
- **参数：** 探查字段、过滤条件
- **步骤：**
  1. DISTINCT 探查字段取值分布
  2. 固化为映射规则后再进入正式分析
- **伪 SQL：**

```sql
SELECT  DISTINCT {{DIM}}, COUNT(*) AS cnt
FROM    {{T_ID}}
GROUP BY {{DIM}};
```

- **输出：** 取值分布表 → 映射规则
- **陷阱：** 这是前置步骤，映射未确认前不做正式结论
- **特别提示：** 禁止凭假设写枚举值——字段取值靠猜会导致过滤条件命中零行

### MTD-08 漏斗转化率分析

- **触发：** "转化率""成功率""漏斗""流失"
- **适用表：** 漏斗表（分区表）
- **参数：** 步骤标记字段、实体 ID、维度（可选）
- **步骤：**
  1. 用 CASE WHEN 标记各步骤节点
  2. COUNT DISTINCT 去重统计
  3. 比率用 NULLIF 防除零
- **伪 SQL：**

```sql
SELECT  COUNT(DISTINCT CASE WHEN {{STEP_1_FLAG}} = 1 THEN {{ENTITY_ID}} END) AS step1_cnt,
        COUNT(DISTINCT CASE WHEN {{STEP_2_FLAG}} = 1 THEN {{ENTITY_ID}} END) AS step2_cnt,
        ROUND(COUNT(DISTINCT CASE WHEN {{STEP_2_FLAG}} = 1 THEN {{ENTITY_ID}} END) * 100.0
              / NULLIF(COUNT(DISTINCT CASE WHEN {{STEP_1_FLAG}} = 1 THEN {{ENTITY_ID}} END), 0), 2) AS conversion_pct
FROM    {{T_FUNNEL}}
WHERE   {{PARTITION_FILTER}} BETWEEN '${start}' AND '${end}';
```

- **输出：** 各步骤数量 + 转化率
- **陷阱：** 漏斗表可能有数据覆盖范围限制（如仅新版本有埋点），不可与全版本数据直接对比
- **特别提示：** 按维度拆分时加 GROUP BY，可定位流失严重的维度值

## L4 决策树（Agent 执行路径）

```
1. 解析意图
   ├─ 命中 L3 场景？ → 取该场景配置（维度/指标/方法链/固化查询）
   └─ 未命中？ → 用 L2 方法临时编排，并建议沉淀为新场景

2. 前置校验
   ├─ 检查"必需输入"列 → 有未提供的项？向用户索取（目标值/文件等）
   ├─ 涉及枚举/映射未知 → 先跑 MTD-07 探查
   ├─ 时间窗口/切换日未定 → 与用户确认
   ├─ 跨时间点分析？ → 标记需换表
   └─ 查看场景"备注"列 → 注意数据起始日期、覆盖范围等限制

3. 执行路径选择
   ├─ 场景有固化查询（FQ-XX）？
   │   └─ 从 fixed_queries.md 取 SQL → 注入 ${param} → 直接执行 → 跳到第 5 步
   └─ 无固化查询？
       ├─ 选表（L0 选表规则）
       └─ 按方法链顺序执行（L2 步骤 + 伪 SQL）
           └─ 每步校验：窗口等长？体量门槛？度量一致？比率指标分子分母分别聚合后再除？

4. （可选）固化建议
   └─ 方法链执行完毕、结果经确认正确 → 建议将该 SQL 固化到 fixed_queries.md

5. 输出（按方法"输出"定义）
   └─ 结论区分"统计显著"与"业务显著"，小样本不下强结论
```

### 全局 Checklist

> 方法链执行时每步必过：

1. **前后/对比窗口等长**，避开大促与异常日。
2. **排行/分层先过体量门槛**：剔除小体量噪声（如占比 < 2%）。
3. **比率指标聚合规则**：分子分母分别 SUM 后再除，不可对率值求平均。
4. **数据不足声明**：查询返回行数 < 10 或时间窗口 < 7 天时，提示"样本量不足，结论仅供参考"。
5. **建议必须可执行**：禁止"优化一下"，必须具体到"XX 维度 XX 指标 XX%，建议 XX 动作"。
