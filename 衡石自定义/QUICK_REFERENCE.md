## 🚀 3步快速上手

### 第1步：创建图表
衡石仪表盘 → 新建图表 → **JS 图表**

### 第2步：拖入字段（严格按顺序）
```
维度1: month_str      (月份)
维度2: second_category (二级品类)  
度量1: GMV            (销售额-求和)
```

### 第3步：粘贴代码
复制 [dynamic_bar_chart_race.js](./dynamic_bar_chart_race.js) 全部内容到代码编辑器 → 应用

## ⚙️ 核心参数速查

```javascript
var updateFrequency = 2000;    // 多久切换一次（毫秒）
var animationDuration = 1000;  // 动画持续多久（毫秒）
var maxBars = 10;              // 显示前几名
```

### 场景推荐配置

| 用途 | updateFrequency | animationDuration | maxBars |
|------|-----------------|-------------------|---------|
| 快速演示 | 1500 | 800 | 10 |
| 详细分析 | 3000 | 1500 | 15 |
| 大屏展示 | 2500 | 1200 | 8 |

## ❗ 常见问题秒解

### Q1: 显示"配置错误"？
✅ 检查是否拖入了 **3个字段**  
✅ 确认顺序：**时间 → 品类 → 度量**

### Q2: 图表空白无数据？
✅ 检查数据源是否有数据  
✅ 确认时间格式统一（如 "2024-01"）  
✅ 打开控制台查看错误信息

### Q3: 动画卡顿？
✅ 减少 `maxBars`（如改为8）  
✅ 增加 `animationDuration`（如改为1500）

### Q4: 想修改颜色？
✅ 在衡石 **样式面板** 中设置（推荐）  
✅ 或修改代码中的 `colors` 数组

##  最佳实践

1. **SQL预聚合**：大数据量时先在SQL层聚合
2. **限制数量**：maxBars ≤ 20，保证性能
3. **适当延时**：updateFrequency ≥ 2000ms，便于观察
4. **清晰标识**：月份格式统一且易读
