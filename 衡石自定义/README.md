# 衡石自定义图表 - 动态柱状图（Bar Chart Race）

##  功能概述

这是一个基于 **ECharts** 和 **衡石分析平台** 的动态柱状图，用于展示**二级品类销售额随时间动态变化的排名过程**。

### 核心特性

✅ **双维度支持**：同时使用时间维度（月份）和二级品类维度  
✅ **动态排名**：销售额越大，排名自动上升，直观展示竞争态势  
✅ **流畅动画**：品类位置平滑过渡，数值实时更新  
✅ **交互控制**：支持播放/暂停、月份快速跳转  
✅ **自动循环**：播放到最后一帧后自动回到第一帧  
✅ **衡石联动**：点击柱子可触发下钻或与其他图表联动

##  快速开始

### 1. 创建自定义图表

在衡石仪表盘中：
1. 点击 **新建图表** → 选择 **JS 图表**
2. 进入代码编辑界面

### 2. 配置数据字段

按以下顺序拖入字段到配置区：

| 轴位置 | 字段类型 | 推荐字段 | 说明 |
|--------|----------|----------|------|
| **维度1** | 时间维度 | `month_str` | 月份字符串，如 "2024-01" |
| **维度2** | 分类维度 | `second_category` | 二级品类名称 |
| **度量1** | 数值度量 | `GMV` | 销售额（求和） |

> ⚠️ **重要**：字段拖入顺序必须严格按照上述顺序，否则图表无法正确识别数据列。

### 3. 粘贴代码

将 [dynamic_bar_chart_race.js](./dynamic_bar_chart_race.js) 文件中的完整代码复制到代码编辑器中。

### 4. 调试预览

点击 **应用** 或 **预览**，查看动态效果。

## 🎛️ 控制面板说明

图表左上角会显示一个半透明的控制面板，包含：

### 播放/暂停按钮
- ** 暂停**：停止自动播放，固定在当前月份
- **▶ 播放**：恢复自动播放，继续动态展示

### 月份选择器
- 下拉框显示所有可用月份
- 点击任意月份，立即跳转到该月份的数据
- 选择后会自动暂停，方便仔细观察

## ⚙️ 参数配置

你可以在代码顶部修改以下参数来调整图表行为：

```javascript
var updateFrequency = 2000;    // 更新频率（毫秒），默认2秒切换一次
var animationDuration = 1000;  // 动画持续时间（毫秒），默认1秒
var maxBars = 10;              // 显示前N名，默认显示前10名
```

### 推荐配置

| 场景 | updateFrequency | animationDuration | maxBars |
|------|-----------------|-------------------|---------|
| 快速演示 | 1500 | 800 | 10 |
| 详细分析 | 3000 | 1500 | 15 |
| 大屏展示 | 2500 | 1200 | 8 |

## 📐 技术架构

### 数据处理流程

```
原始数据 (params.data.data)
    ↓
按时间+品类聚合 (processedData[time][category])
    ↓
按时间排序 (sortedTimes)
    ↓
构建排名数据 (chartData[{time, data: [{name, value}]}])
    ↓
逐帧渲染 (updateChart)
    ↓
ECharts 可视化 (myChart.setOption)
```

### 关键函数说明

| 函数名 | 功能 | 调用时机 |
|--------|------|----------|
| `renderChart()` | 主渲染入口，初始化图表 | 首次加载 |
| `createControlPanel()` | 创建控制面板UI | renderChart内 |
| `updateChart()` | 更新到指定帧 | 定时器触发/手动选择 |
| `startAnimation()` | 启动自动播放 | 初始化和点击播放 |
| `pauseAnimation()` | 暂停自动播放 | 点击暂停/选择月份 |
| `findIndexByValue()` | ES5兼容的数组查找 | yAxis标签格式化 |

## 🔗 衡石交互集成

### 点击下钻

代码已内置点击事件处理：

```javascript
myChart.on('click', function(echartsEvent) {
  params.onHSClickHandler([{
    data: echartsEvent.name,      // 品类名称
```

- 执行预设的交互动作

当其他图表被点击时，本图表会自动高亮对应的品类（通过 `params.currentHighlight` 实现）。

## 🐛 常见问题排查

### 问题1：图表显示"配置错误"

**原因**：字段拖入顺序不正确或数量不足

**解决**：
1. 确保拖入了 **3个字段**（2个维度 + 1个度量）
2. 检查顺序：时间维度 → 品类维度 → 销售额度量
3. 刷新页面重新加载

### 问题2：图表无数据或空白

**原因**：数据源为空或格式不正确

**解决**：
1. 检查数据源是否有有效数据
2. 确认时间字段格式统一（如都是 "2024-01" 格式）
3. 确认销售额字段为数值类型
4. 打开浏览器控制台查看 `console.log` 输出

### 问题3：动画卡顿或不流畅

**原因**：数据量过大或动画参数设置不当

**解决**：
1. 减少 `maxBars` 值（如从15改为10）
2. 增加 `animationDuration`（如从800改为1200）
3. 增加 `updateFrequency`（如从1500改为2500）

### 问题4：控制面板不显示

**原因**：DOM元素创建失败或被遮挡

**解决**：
1. 检查浏览器控制台是否有JavaScript错误
2. 确认 `params.createElement` 和 `params.appendChild` API可用
3. 尝试刷新页面

### 问题5：月份选择器选项为空

**原因**：时间点数据未正确提取

**解决**：
1. 检查 `timeIndex` 是否正确（应为0）
2. 确认时间字段有有效值（非null/undefined）
3. 在控制台打印 `sortedTimes` 查看结果

## 🎯 最佳实践

### 1. 数据准备建议

- **时间字段**：使用统一的字符串格式，如 "YYYY-MM" 或 "YYYY年MM月"
- **品类字段**：确保品类名称简洁明了，避免过长文本
- **度量字段**：使用求和聚合，确保数值准确

### 2. 性能优化

- 数据量较大时，建议在SQL层面先做预聚合
- 限制显示的品类数量（maxBars不宜超过20）
- 适当调整动画时长，避免过于频繁的重绘

### 3. 用户体验

- 首次加载时显示加载提示
- 提供清晰的月份标识
- 保留足够的播放时间让用户观察变化

### 4. 大屏适配

- 调整 `fontSize` 适应大屏分辨率
- 增加 `maxBars` 展示更多品类
- 延长 `updateFrequency` 让观众有足够时间阅读
