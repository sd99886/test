## 架构总览
下图展示了整个系统的端到端流程：Notebook 读取配置与 SQL，连接 MaxCompute，执行 SQL 并通过隧道加速下载结果；同时API服务提供REST接口供外部系统调用。

```mermaid
sequenceDiagram
participant NB as "Notebook(query.ipynb)"
participant API as "API服务(app.py)"
participant CFG as "配置(config.py)"

participant MC as "MaxCompute(ODPS)"
participant DF as "结果(pandas DataFrame)"
participant WEB as "管理后台(admin.html)"
NB->>CFG : 读取访问凭据与参数
NB->>SQL : 读取查询语句
NB->>MC : 建立连接并执行 SQL
MC-->>NB : 返回实例与 LogView
NB->>MC : 等待完成并开启隧道下载
MC-->>DF : 返回结果 DataFrame
NB-->>NB : 渲染结果并可选导出 CSV/Excel
WEB->>API : 通过Web界面编辑SQL
API->>SQL : 保存SQL文件
API->>MC : 执行SQL查询
MC-->>API : 返回查询结果
API-->>WEB : 返回JSON格式数据
```

### 组件六：数据接口API服务快速入门

#### 本地开发模式
```bash
cd 数据接口-for冬冬
python app.py
```

访问地址：
- **API文档首页**: http://localhost:5000/
- **数分管理后台**: http://localhost:5000/admin
- **接口列表**: http://localhost:5000/api/queries

#### API Key 认证配置
编辑 `config.py` 文件，配置API Key认证：
```python
# API Key 认证配置
API_KEY = "your-api-key-here"  # 留空字符串 "" 表示不启用认证（本地开发用）
```

#### 基本使用方法
1. **编写SQL**：访问管理后台 http://localhost:5000/admin
2. **保存并发布**：点击「保存并发布」→ 自动生成接口 `/api/query/{名称}`
3. **调用接口**：使用HTTP GET请求获取数据

### 组件七：生产环境部署

#### Gunicorn + Nginx 部署（推荐）
```bash
# 安装 gunicorn
pip install gunicorn

# 启动服务（4个worker进程）
gunicorn -w 4 -b 0.0.0.0:5000 app:app

# 或使用 systemd 管理服务
sudo systemctl start data-api
```

#### Docker 部署
```dockerfile
FROM python:3.11-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 5000
CMD ["gunicorn", "-w", "4", "-b", "0.0.0.0:5000", "app:app"]
```

#### 一键部署脚本
```bash
# 使用提供的部署脚本
chmod +x deploy.sh
sudo bash deploy.sh
```

## 性能注意事项
- 启用 Instance Tunnel 加速数据传输，显著降低下载耗时
- 查询耗时分为 SQL 执行耗时与结果下载耗时，便于定位瓶颈
- API服务支持并发请求处理，建议使用Gunicorn多进程部署
- 如需进一步优化，可参考 LogView 链接分析执行计划

## 故障排查指南
- **无法启动或内核不可用**
  - 确认 Python 3.13.2 已正确安装并加入 PATH
  - 在终端执行 Python 版本命令验证
- **访问凭据错误或连接失败**
  - 检查 config.py 中的 AccessKey ID/Secret、项目名与 Endpoint
  - 确认已复制示例配置为真实配置
- **查询超时**
  - 检查 SQL 超时时间配置
  - 优化 SQL，减少扫描数据量
- **导出 Excel 失败**
  - 安装 openpyxl 后重试
- **笔记本语法错误（示例）**
  - 示例 Notebook 中包含无效的命令行代码，属于示例错误，不影响主流程
- **API服务启动失败**
  - 检查端口5000是否被占用
  - 确认所有依赖包已正确安装
  - 查看应用日志输出
- **API Key认证失败**
  - 确认config.py中API_KEY配置正确
  - 检查请求头中是否正确传入X-API-Key
- **跨域访问问题**
  - 确认Flask-CORS已正确配置
  - 检查浏览器控制台是否有CORS错误
