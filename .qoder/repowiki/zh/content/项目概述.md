## 引言
本项目是一个基于 Jupyter Notebook 的极简数据分析与 MaxCompute 查询工具，现已扩展为三种使用形态：**命令行版本（CLI）**、**Notebook 版本**和**数据接口API服务**。所有版本均支持从外部 SQL 文件读取查询语句并执行，结果自动保存到本地文件或通过REST API提供。项目采用全新的Git安全系统架构，将敏感信息保护机制完全迁移到独立的git_security文件夹中，提供完整的自动化工具链和文档体系。

- **项目目标**：为数据分析与机器学习开发提供便捷、可复用、安全的查询工具链，支持多种使用场景
- **核心功能**：SQL 查询执行、结果导出、REST API服务、性能监控、完整的Git敏感信息保护
- **适用场景**：数据分析、数据挖掘、报表生成、模型训练数据准备、Python 生态集成、AI平台数据服务

## 项目结构
项目采用zip包模块化架构，并实现了Git安全系统的完全重构，主要由以下三大部分组成：
- **CLI 版本**：独立的 Python 脚本集合，包含配置、主程序、SQL 文件、输出目录与验证/修复工具
- **Notebook 版本**：Jupyter Notebook 环境，配合配置与 SQL 文件，支持交互式查询与结果可视化
- **数据接口API服务**：基于Flask的REST API服务，提供Web管理后台和HTTP接口访问
- **Git安全工具包**：完整的自动化工具链，包含主文档、详细指南、快速参考和演示脚本

## 核心组件
本项目现包含四大核心组件：

### 1) Jupyter Notebook 环境
- **作用**：提供交互式数据分析与可视化能力，适合探索性分析与快速原型开发
- **关键文件**：query.ipynb、config.py、sql/query.sql
- **特点**：支持从外部 SQL 文件读取查询语句，便于与 CLI 版本共享 SQL 逻辑

### 2) 业务逻辑模块（CLI）
- **作用**：封装 MaxCompute 连接、SQL 加载、查询执行、结果保存与性能监控
- **关键文件**：main.py、config.py、verify_all_optimizations.py、auto_fix_optimizations.py
- **特点**：启用 Instance Tunnel 加速、显示 LogView 链接、输出详细耗时统计

### 3) 数据接口API服务（全新组件）
- **作用**：提供REST API服务，供外部AI平台通过HTTP请求获取MaxCompute数据
- **关键文件**：app.py、config.py.example、templates/、sql/
- **特点**：Flask Web框架、API Key认证、Web管理后台、生产环境部署支持

### 4) Git敏感信息保护系统（全新重构）
- **作用**：提供完整的自动化工具链，确保AccessKey等密钥不被意外提交到版本库
- **关键文件**：git_security_tool.py、demo_git_security.py、README.md、GIT_SECURITY_GUIDE.md
- **特点**：模块化设计、完整的文档体系、一键初始化和检查功能

**技术栈概览**
- **Python 3.13.2 内核**（Notebook 环境）
- **pyodps**（MaxCompute Python SDK）
- **pandas**（数据处理）
- **Jupyter Notebook**（交互式开发）
- **Flask 3.0**（Web框架）
- **Gunicorn**（生产环境WSGI服务器）
- **Nginx**（反向代理）
- **Git**（版本控制与安全保护）

## 故障排除指南
常见问题与解决方案

- **GitHub 阻止推送**
  - 症状：远程拒绝包含密钥的推送
  - 解决：使用git_security_tool.py --check检查状态，必要时重写 Git 历史或使用 BFG 清理工具

- **连接失败**
  - 症状：AccessKeyIdNotFound 或 Invalid credentials
  - 解决：检查 config.py 中 AccessKey 配置、确认账号权限

- **查询超时**
  - 症状：Timeout 或长时间无响应
  - 解决：增加 SQL_TIMEOUT、优化 SQL、减少返回数据量

- **速度仍然较慢**
  - 症状：即使启用 Tunnel 仍较慢
  - 解决：查看 LogView 执行计划、优化 SQL、调整 MAX_RESULT_ROWS

- **Tunnel 连接失败**
  - 症状：无法连接到 Tunnel Endpoint
  - 解决：检查网络连通性、添加防火墙白名单

- **API服务启动失败**
  - 症状：端口占用或依赖缺失
  - 解决：检查5000端口占用、安装requirements.txt依赖、查看Flask日志

- **API认证失败**
  - 症状：401/403错误
  - 解决：检查API Key配置、确认请求头或URL参数正确

- **跨域访问问题**
  - 症状：浏览器控制台CORS错误
  - 解决：确认flask-cors已启用、检查Nginx配置

- **Git安全检查失败**
  - 症状：git_security_tool.py --check报告敏感信息
  - 解决：运行git_security_tool.py --init重新初始化，或使用--template仅生成模板
