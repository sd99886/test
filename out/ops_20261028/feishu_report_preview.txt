7. 附录：关键指标口径
  达成率 = 实际 / 目标（目标为「正常目标」类型）；时间进度 = 截止日 / 当月天数（本期 截止到10月28日，即 28/31 = 90.32%）；落后/超时间进度 = 达成率 − 时间进度（以 % 表示）；差额/超额数值 = 时间进度差 × 对应目标值（落后为差额，超过为超额）。
  环比 =（本期 − 上月同期）/ 上月同期；上月同期 = 起止日各回拨 1 个月（本期 2026-10-01~2026-10-28，环比期 2026-09-01~09-28）。
  同比 =（本期 − 去年同期）/ 去年同期（同比期 2025-10-01~10-28）；第 3 章对照《经营情况模板》采用同比口径。
  占比 = 该维度行 / 全部维度合计（按各自周期计算）；占比变化以 % 表示。
  CTR = 商列点击UV / 商列浏览UV；CVR = 销量 / 详情页UV；UV产出（UV价值）= 销售额 / 详情页UV；加车率 = 商列加车UV / 商列浏览UV；平均价 = 销售额 / 销量；款效 = 销售额 / 在架SKC。
  退件率 = 退货数量 / 销量；退货率 = 退款总额 / 销售额。
  汇总口径：整体/大类/品类/新老品汇总均由明细行加总；对比期原始值由「本期值 ÷ (1+增长率)」还原，增长率缺失或 ≤ -100% 的行按对比期=0 处理（销售额口径涉及 4/52 行）。
  口径差异：第 2 章为 2026-10 月度口径（仅当期，进度基准=时间进度）；第 3 章为 2026-10-01~2026-10-28 窗口口径。两者数值不可直接混用。
  合并表口径（表3-1/3-2）：销售额/销量/在架skc/UV 等为本期明细加总，环比=与上月同期（2026-09-01~09-28）对比、同比=与去年同期（2025-10-01~10-28）对比；占比为部门内/大类内占比；上新数为当月上架款数（月度口径，与 2.4 一致，环比/同比基于上月同期/去年同期派生查询）。
